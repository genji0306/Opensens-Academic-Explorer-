**Hash-command correction:** the supplied literal `find . -type f | sort | xargs
shasum -a 256 | shasum -a 256` splits filenames containing spaces. On this bundle
it emitted 229 error lines and the incomplete digest
`a6d4259338cc0006a8c72dcf8e6b280fda82cbb8bb4fd023299979ff57e96a50`.
The supplied expected digest matches the complete sorted per-file hash lines,
with spaces preserved. This space-safe equivalent reproduces the correct pin:

```bash
(
  set -o pipefail
  cd "$MVE_VERSIONS/153.0.8010.54"
  find . -type f | LC_ALL=C sort |
    while IFS= read -r file; do shasum -a 256 "$file" || exit; done |
    shasum -a 256
)
```

The Python verifier uses the same `./` relative paths, two spaces after each
per-file hash, and trailing newlines; it does not follow symlinks. The lock stores
no machine-specific bundle path. Opus supplies `--chrome` at runtime.
