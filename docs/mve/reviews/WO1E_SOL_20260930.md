# WO-1e recapture admission and failed-attempt recovery

## Finding and fix

The WO-6c snapshot IDs derive from module and source, so the 16 IDs repeat across capture plans. The old quarantine reader treated an active directory with the same ID and no `complete.json` as superseded evidence. During the first worker recapture, the four new snapshot directories were in progress and admission refused them. The reader now uses the active receipt or sealed plan for native attempts, a completion receipt for finished snapshots, and a sealed different-plan native attempt for in-progress snapshots. It still checks the complete 20-move superseded record, every moved directory and file hash, and the quarantined artifact set.

The failed attempt recovery writes a sealed `mve-wo6c-failed-attempt-quarantine-v1` record before moving the failed native attempt and any partial snapshots of its batch. It accepts only a sealed `plan.json` with a matching `receipt.json` whose status is `failed`. It refuses captured or accepted attempts and completed snapshots. The reader verifies the record and the moved files on every admission. No file is deleted or overwritten. A worker exception now leaves `worker-traceback.txt` in the attempt directory, with exception type, a message only when it contains no absolute path, and bounded stack locations. The parent `traceback.txt` remains separate.

The real WO-6c evidence was **read only**. In a temporary copy, its old 20-move quarantine admitted, the actual failed `native/0` (plan `604055543b648fdcbe01f7c627df5d811a4d4d9e26545e10022724e1815760e9`) was set aside and admitted, and four in-progress same-ID recapture directories admitted under the post-fix plan. The real WO-1b evidence was **read only**. In a temporary copy, the 66 active completions admitted; copying the four IDs from `partial-spectral-contrast-2-153` back into active snapshots admitted 70 completions while retaining the quarantine record. The WO-1b manifest hash `d286a45abc8187fd06bd63a1957d34c809ca0c82abaf9aad8485ef3b9abe7620` did not change.
